📊 Sales Performance Analysis

This project analyzes a retail sales dataset using Python to evaluate business performance through key performance indicators (KPIs), interactive visualizations, and actionable business recommendations.

---
🎯 Objectives

- 📈 Analyze sales performance

- 🛍️ Analyze product categories
- 📊 Evaluate business KPIs
- 💡 Provide data-driven business recommendations
